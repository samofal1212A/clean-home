# Clean Home

Адаптивний вебсайт для клінінгової компанії, що презентує послуги професійного прибирання квартир, будинків та офісів.

## 📌 Про проєкт

**Clean Home** — навчальний frontend-проєкт, створений для закріплення практичних навичок HTML та CSS.

Мета проєкту — розробити сучасний та зручний вебсайт клінінгової компанії, на якому користувачі можуть ознайомитися з послугами, переглянути орієнтовні ціни та залишити заявку.

Під час розробки основна увага приділялася семантичній HTML-структурі, організації елементів за допомогою CSS Grid і Flexbox та адаптації сторінки до різних розмірів екрана.

## ✨ Основні секції

- **Головний екран** — презентація компанії та її послуг.
- **Наші переваги** — досвідчені працівники, екологічні засоби, доступні ціни та швидкий виїзд.
- **Наші послуги** — шість напрямків клінінгу:
  - Генеральне прибирання.
  - Щоденне прибирання.
  - Миття вікон.
  - Прибирання після ремонту.
  - Хімчистка меблів.
  - Прибирання офісів.
- **Наші ціни** — картки з орієнтовною вартістю послуг.
- **Відгуки клієнтів** — блок із відгуками та оцінками.
- **Форма заявки** — поля для введення імені, телефону, вибору послуги та додаткових побажань.
- **Футер** — навігація, контактна інформація та соціальні мережі.

## 🛠 Використані технології

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- Responsive Web Design

## 📱 Адаптивність

Для адаптації сторінки до різних розмірів екранів використовувалися:

- CSS Media Queries;
- CSS Grid для побудови сіток;
- Flexbox для вирівнювання та розташування елементів;
- гнучкі розміри блоків і зображень.

## 🎨 Особливості реалізації

- Семантична структура HTML.
- Картки послуг та тарифів.
- Hover-ефекти для інтерактивних елементів.
- Адаптивне розташування контенту.
- Форма з HTML-атрибутами валідації `required`.
- Стилізація станів фокусу для елементів форми та посилань.

## 🚀 Запуск проєкту

1. Клонуйте репозиторій:

   ```bash
   git clone https://github.com/samofal1212A/clean-home.git
   ```

2. Перейдіть до папки проєкту:

   ```bash
   cd clean-home
   ```

3. Відкрийте файл `index.html` у браузері.
